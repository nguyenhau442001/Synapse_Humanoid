DESIGN NOTES

Eyes are camera lenses: the robot’s right eye holds the IMX219, the left is a matching bezel (Zero 3W has one CSI port)
Clear dome gets a flat window in front of the camera, so the image is not distorted
Ears are sound receivers: one I2S MEMS mic (INMP441) behind each grille, for sound direction
Neck stem now drops into an orange collar ring that sits on the torso
Vietnam flag patch on the chest; every part keeps ≥ 3 mm fillets

Same 20-DoF skeleton, joint axes and 303 mm height as A1. Only the shell changes.
