MICO · v2.0 · EXPRESSION SET

Seven faces, one OLED

Each state is tied to something Mico senses or does, not just decoration

NeutralIdle, listening
HappyGreeting, wave, task done
CuriousNew object or voice detected
SurprisedSudden sound, push, near-fall
SadPath blocked, battery low
SleepyIdle timeout, about to rest
ProcessingPlanning a path, thinking
HOW IT WORKSOne 2.42″ mono OLED (SSD1309, 128 × 64) draws both eyes and the mouth behind the visor.The Radxa picks the state from what the camera, mics and planner report; the head servos tilt to match.The camera has its own window on the forehead, so no expression ever covers it.
